GitHub 연동 키 교체

?
연동 키와 GitHub 토큰은 같은 값입니다.
  1. GitHub 새 토큰 발급을 엽니다. 이름은 WindowsPet-update, 소유자는 popcorn33788로 둡니다.
  2. Expiration에서 원하는 만료일(예: 90일)을 고릅니다. 만료 전에 교체하면 다운로드 중단을 피할 수 있습니다.
  3. Repository access → Only select repositories에서 windows-pet-private만 선택합니다.
  4. Permissions → Repository permissions → Contents를 Read and write로 설정합니다. 기본 Metadata 외 추가 권한은 필요 없습니다.
  5. Generate token을 누르고 표시된 github_pat_… 값을 복사합니다. 원문은 생성 직후에만 표시되므로 개인 비밀번호 보관함에 보관하세요. 채팅에 보내지 마세요.
  6. 아래 칸에 새 토큰을 붙이고 ‘연동 키 교체’를 누릅니다. 성공을 확인한 뒤 GitHub 토큰 목록에서 이전 토큰을 폐기합니다. 최초 설정코드는 다시 필요하지 않습니다.

새 토큰의 연결을 확인한 후 저장합니다. 잘못된 키이면 기존 키를 유지합니다. 입장 비밀번호·계정·기존 배포 파일은 바뀌지 않습니다.
